# Module bundle guidance

The root and `/static` entries do not import geographic JSON. Import only the datasets your map uses to minimize application bundles. `/data/static` includes the complete static map without interactive lookup collections; `/data/full` adds those collections for interactive maps. The optional `/guide` entry includes a small overview and loads detail only on request. Current measured sizes and data inclusion checks are in [the guide bundle report](guide-bundle-report.md), generated by `pnpm report:guide`.
